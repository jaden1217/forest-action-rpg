# 숲의 모험 (Forest Action RPG)

브라우저에서 돌아가는 도트(픽셀아트) 액션 RPG. 스토리 없이 **탐험 + 실시간 전투**에 집중.

## 컨셉
- 스토리/대사 없음. 맵을 돌아다니며 무기를 휘둘러 몬스터를 잡는 액션 RPG
- 모든 그래픽은 도트(픽셀아트). 외부 이미지 파일 없이 코드로 픽셀을 찍어서 생성
- 초기 지역: **숲**
- 초기 몬스터: **슬라임** (레벨 1~5, 랜덤 위치 스폰, 레벨마다 체력/공격력/속도/크기/색상 차이)

## 실행 방법
`index.html` 을 브라우저로 열면 끝. 빌드 도구·설치 불필요.

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space / J / 마우스 좌클릭 | 무기 휘두르기 |

## 파일 구조
```
index.html        진입점
css/style.css     화면 레이아웃 (픽셀 확대 렌더링)
js/config.js      모든 밸런스 수치 (여기만 고치면 게임 난이도 조정됨)
js/util.js        수학/랜덤 유틸
js/sprites.js     도트 스프라이트 정의 + 절차적 생성 (나무, 풀, 이펙트)
js/world.js       숲 맵 생성, 충돌, 지형 렌더링
js/player.js      플레이어 이동 / 공격 / 레벨업
js/slime.js       슬라임 AI / 레벨별 능력치 / 스폰
js/fx.js          파티클, 데미지 숫자, 화면 흔들림
js/ui.js          HUD, 픽셀 폰트
js/game.js        게임 루프, 카메라, 전체 조립
```

## 3개월 로드맵 (주 10시간 x 12주 = 약 120시간)

### 1개월차 — 핵심 시스템 (~40h)
- [x] **1주차**: 프로젝트 뼈대, 도트 렌더링 파이프라인, 숲 맵, 플레이어 이동/충돌
- [x] **1주차**: 무기 휘두르기 공격, 슬라임 랜덤 스폰(레벨 1~5), 전투/피격/사망
- [ ] **2주차**: 아이템 드랍, 인벤토리, 회복 포션
- [ ] **3주차**: 장비 시스템 (무기 교체 → 공격 범위/속도/데미지 변화)
- [ ] **4주차**: 저장/불러오기(localStorage), 미니맵

### 2개월차 — 콘텐츠 확장 (~40h)
- [ ] **5주차**: 몬스터 추가 (버섯, 늑대 등) + 원거리 공격 패턴
- [ ] **6주차**: 지역 확장 — 깊은 숲 / 동굴 입구, 지역별 몬스터 분포
- [ ] **7주차**: 스킬 시스템 (대시, 강공격, 쿨다운)
- [ ] **8주차**: 첫 보스 (거대 슬라임) — 패턴형 전투

### 3개월차 — 완성 & 폴리싱 (~40h)
- [ ] **9주차**: 상점/NPC, 골드, 강화
- [ ] **10주차**: 사운드/BGM, 타격감 강화(히트스톱, 이펙트)
- [ ] **11주차**: 최종 보스, 밸런싱
- [ ] **12주차**: 버그 수정, 최종 플레이테스트, 배포

## 밸런스 수정하는 곳
`js/config.js` 하나만 열면 플레이어 속도, 공격력, 슬라임 레벨별 능력치, 스폰 수를 전부 바꿀 수 있음.
