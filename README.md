# 숲의 모험 (Forest Action RPG)

브라우저에서 돌아가는 도트(픽셀아트) 액션 RPG. 스토리 없이 **탐험 + 실시간 전투**에 집중.

## 컨셉
- 스토리/대사 없음. 맵을 돌아다니며 무기를 휘둘러 몬스터를 잡는 액션 RPG
- 모든 그래픽은 도트(픽셀아트). 외부 이미지 파일 없이 코드로 픽셀을 찍어서 생성
- 초기 지역: **숲**
- 몬스터: **슬라임 / 버섯 / 늑대** (레벨 1~23, 지역별로 나오는 종류와 레벨이 다르다)

## 실행 방법
`index.html` 을 브라우저로 열면 끝. 빌드 도구·설치 불필요.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| Space / 마우스 좌클릭 | 무기 휘두르기 — **마우스가 가리키는 방향으로 나간다** |
| Shift | 대시 (최대 2회 충전) |
| Q | 강공격 (Lv10 해금) |
| R | 회전베기 (Lv20 해금) |
| E | 회복 포션 마시기 |
| I / Tab | 인벤토리 열기/닫기 |
| (포션 줍기) | 바닥 포션에 다가가면 자동 획득 |
| F | 발밑 무기와 교체 (손에 있던 무기는 그 자리에 둠) |
| M | 전체 지도 열기/닫기 (여는 동안 시간 정지) |
| N | 새 게임 (Y/N 확인 후 진행) |

> 무기는 자동으로 바뀌지 않는다. 지나가다 좋은 무기가 나쁜 무기로 바뀌는 사고를 막기 위해,
> 무기 위에 서면 `F SWAP` 안내가 뜨고 **F 를 눌러야** 교체된다.

### 겨냥
이동은 WASD, 겨냥은 마우스로 따로 한다. **왼쪽으로 도망치면서 오른쪽을 때리는 것**이 가능하다.
휘두르기 시작한 순간의 각도로 고정되므로, 휘두르는 도중 마우스를 돌려도 판정은 바뀌지 않는다.
마우스를 한 번도 안 움직였다면 걸어간 방향을 그대로 쓴다.

## 스킬 (7주차)
평타 말고 따로 쓰는 공격 수단. **플레이어 레벨로 열리고** 각자 쿨다운이 있다.
위력을 고정값이 아니라 **평타 데미지 × 배수**로 정했기 때문에, 레벨이 오르면 스킬도 같이 세진다
— 성장 축이 레벨이라는 원칙을 스킬에도 그대로 적용했다.

| 키 | 스킬 | 해금 | 쿨다운 | 위력 | 성격 |
|---|---|---|---|---|---|
| `Q` | **HEAVY** 강공격 | Lv10 | 6.0초 | 평타 x2.6 | 앞으로 파고들며 **넓게(판정각 1.5) 한 방**. 사거리도 길고 크게 날려보낸다 |
| `R` | **SPIN** 회전베기 | Lv20 | 10.5초 | 평타 x1.5 | **사방 360도**를 0.17초 간격으로 연속 타격. 둘러싸였을 때 빠져나오는 기술 |

실측(반경 26px에 12마리를 둘러 세우고 한 번씩 사용):

| | 맞은 수 | 데미지 |
|---|---|---|
| 평타 | 3마리 | 46 |
| 강공격 | 3마리 | **122** |
| 회전베기 | **12마리 전부** | 143 (연속타 합산) |

- 스킬을 쓰는 동안에는 제자리에 묶인다(강공격은 스스로 앞으로 나간다). 평타는 나가지 않는다
- **대시는 스킬을 끊는다** — 빠져나가는 수단이므로 언제든 취소할 수 있다
- 쿨다운이 도는 중에 눌러도 입력이 기억됐다가(0.18초) 풀리는 즉시 나간다
- 아직 안 열린 스킬을 누르면 필요한 레벨이 뜬다
- 화면 아래 가운데 **스킬 바**에 키·이름·쿨다운·잠김이 표시된다 (쓸 수 있으면 테두리가 켜진다)

### 대시
**충전식으로 최대 2칸**까지 모아뒀다가 연달아 쓸 수 있다. 한 칸은 1.7초마다 다시 찬다.
대시하는 동안 **0.22초 무적**이라 늑대의 돌진이나 날아오는 포자를 통과해 피할 수 있다.
WASD 를 누르고 있으면 그쪽으로, 아무것도 안 누르면 겨냥한 쪽으로 구른다.
대시하면 휘두르던 동작은 끊기고, 남은 충전은 HUD 왼쪽 아래 `DASH` 게이지로 보인다.

## 지역 (6주차)
세 구역이 **삼각형으로 모여 서로 전부 맞닿아** 있다. 어느 하나가 다른 하나를 둘러싸지 않는다.

```
      깊은 숲   동굴 지대
           \     /
          숲 가장자리
```

세 지역의 중심을 맵 한가운데를 둘러싸고 120도씩 벌려 놓은 뒤, 모든 타일을 가장 가까운 중심에
배정한다(경계 거리에 노이즈를 더해 울퉁불퉁하게 만든다). 그래서 각자 자기 구역을 가지면서도
**세 지역이 서로 경계를 맞대고**, 셋이 만나는 지점이 맵 한가운데에 생긴다.
삼각형이 놓이는 방향은 맵마다 달라 매번 다른 배치가 나온다.

플레이어는 **숲 가장자리 한복판**에서 시작한다 (맵 한가운데가 아니다).
어느 지역으로든 바로 넘어갈 수 있으므로, 준비가 되면 곧장 동굴 지대로 갈 수도 있다.

| 지역 | 바닥 | 나무 | 주력 몬스터 | 몬스터 레벨 |
|---|---|---|---|---|
| **FOREST EDGE** 숲 가장자리 | 밝은 잔디, 꽃 | 활엽수 위주 | 슬라임 70% | **1~6** |
| **DEEP FOREST** 깊은 숲 | 그늘진 잔디, 솔잎 | **침엽수 빽빽** (밀도 1.6배) | 늑대 50% | **7~15** |
| **CAVE MOUTH** 동굴 지대 | 돌바닥, 자갈 | 나무 드묾, 고사목 | 버섯 60% | **15~23** |

- 동굴 지대에는 **동굴 입구**가 이정표로 서 있다 (맵 크기에 비례해 20곳 남짓). 미니맵에 주황 사각형으로 찍혀서 멀리서도 찾을 수 있다
  (지금은 들어갈 수 없는 장식 — 8주차 보스방 자리로 쓸 예정)
- 지역을 넘어서면 화면 위에 이름이 잠깐 뜨고, 미니맵 위에는 지금 지역이 늘 표시된다
- 전체 지도(`M`)에서 지역이 색으로 구분되므로 **어디로 가야 강해지는지**가 한눈에 보인다

> 깊은 지역일수록 몬스터 레벨이 높아 **경험치도 훨씬 많이 준다.**
> 레벨이 성장의 축이므로, 감당할 수 있는 선에서 더 깊이 들어가는 것이 곧 빨리 강해지는 길이다.

맵 전체에 몬스터 **250마리**가 상주한다(`CONFIG.spawn.maxAlive`). 화면에 평균 4마리 안팎,
빽빽한 곳에서는 열 마리 넘게 보인다. 죽으면 2.5~6초 뒤 맵 어딘가에 다시 등장해 총 수가 유지된다.

## 몬스터
몬스터 레벨은 **1~23**이다. 레벨별 능력치를 표로 적는 대신 곡선으로 만든다
(`buildLevels` 가 시작값 × 레벨당 증가율로 23줄을 생성).

| 항목 | 레벨당 | 1레벨 → 23레벨 |
|---|---|---|
| 체력 | +11.5% | 약 11배 |
| 공격력 | +8.5% | 약 6배 |
| 크기 | +2.2% | 약 1.6배 |
| 이동속도 | +1.0% | 거의 그대로 (도망칠 수 있어야 하므로) |
| 넉백 저항 | −1.2% | 고레벨일수록 덜 밀림 |

레벨 숫자가 23까지 가므로, 색은 **5등급으로 묶어서** 보여준다
(1~4 초록 / 5~8 청록 / 9~13 파랑 / 14~18 보라 / 19~23 빨강). 색만 보고 위험도를 가늠할 수 있다.

| 몬스터 | 성격 | 공격 방식 | 상대법 | 떨구는 무기 |
|---|---|---|---|---|
| **슬라임** | 기본 | 폴짝폴짝 다가와 몸통 박치기 | 거리를 재며 휘두르기 | 단검 |
| **버섯** | 포탑 | 제자리에 뿌리내린 채 **포자를 쏜다** (L8부터 3발, L16부터 5발) | 부풀어오르는 예고를 보고 옆으로 피하기 (대시로 통과 가능) | 도끼 |
| **늑대** | 돌격 | 빠르게 붙어 웅크린 뒤 **직선 돌진** | 웅크릴 때 옆으로 비키고, 돌진 뒤 빈틈에 때리기 | 검 |

> 늑대는 셋 중 체력이 가장 낮다(빠르고 세게 때리는 대신 물렁하다).
> 다만 예고 동작을 보기도 전에 한 대에 죽어버리면 피하는 재미가 사라지므로, 최소 두 대는 버티도록 잡혀 있다.

- **버섯**은 쫓아오지 않는다. 대신 사거리 안이면 계속 쏘므로 "붙어서 없앨까 / 돌아갈까"를 고르게 된다.
  조준은 부풀어오르기 시작할 때 고정되므로, 예고를 본 뒤 옆으로 움직이면 빗나간다.
- **늑대**는 돌진 방향이 웅크릴 때 정해진다. 웅크리는 중에 때리면 돌진이 끊긴다.
  돌진 뒤 빈틈(0.55초)이 가장 때리기 좋은 순간이다.
- 공격 직전에는 몸 위에 **`!`** 가 깜빡인다.

### 몬스터를 추가하려면
`js/enemy.js` 의 `Enemy` 를 상속해 `think()` 와 `drawBody()` 만 채우면 된다.
체력·피격·넉백·사망·레벨 표시·벽 끼임 탈출은 기반 클래스가 처리한다.
만든 뒤 `js/game.js` 의 `ENEMY_TYPES` 에 한 줄, 각 지역의 `typeWeights` 에 등장 확률을 넣는다.

## 무기

### 종류 — 셋의 성능은 같다
데미지를 고정값이 아니라 **쿨다운에 비례하는 배수**로 두어 초당 데미지가 정확히 같다.
어떤 무기를 들어도 강함이 같고, 차이는 "한 방이 무거운가 / 자주 때리는가"라는 손맛뿐이다.

| 무기 | 한 방 배수 | 쿨다운 | 초당 데미지 | 사거리 | 판정각 | 넉백 |
|---|---|---|---|---|---|---|
| DAGGER 단검 | x0.70 | 0.28s | **기본 x2.5** | 19 | 0.86 | x0.70 |
| SWORD 검 | x1.00 | 0.40s | **기본 x2.5** | 21 | 0.95 | x1.00 |
| AXE 도끼 | x1.55 | 0.62s | **기본 x2.5** | 23 | 1.04 | x1.55 |

> 사거리와 판정각도 어느 하나가 확실히 낫지 않도록 차이를 좁게 잡았다.
> 인벤토리(`I`)에서 `DPS` 값을 보면 세 무기가 같다는 걸 직접 확인할 수 있다.

### 무기 레벨 — 거들 뿐이다
무기 레벨도 몬스터와 같은 **1~23**이지만, 레벨당 **+2.5%** 로 아주 완만하다 (L1 x1.00 → L23 x1.55).
칼날 색은 몬스터와 같은 5등급 규칙을 따른다 (무쇠 → 초록 → 파랑 → 보라 → 황금).

**최종 데미지 = 플레이어 기본 공격력 x 무기 종류 배수 x 무기 레벨 배수**

## 성장은 레벨 중심이다
이 게임에서 강해지는 주된 수단은 **레벨업**이다. 좋은 무기를 주우면 조금 수월해질 뿐,
판을 뒤집는 건 레벨이다.

| 무엇을 올렸나 | 데미지 변화 | 기여도 |
|---|---|---|
| **플레이어 레벨 1 → 30** (무기 L1 고정) | 7 → 65 | **x9.3** |
| 무기 레벨 L1 → L23 (플레이어 Lv1 고정) | 7 → 11 | x1.55 |

- 레벨당 **공격력 +2.0 / 최대체력 +8** (`CONFIG.levelUp`)
- 레벨이 무기보다 **약 6배** 더 크게 작용한다

자연스러운 속도로 진행하면 전 구간에서 **3~5대**에 몬스터가 쓰러진다.
사냥을 많이 해서 레벨을 앞서 올리면 더 적은 타수로 잡히는데, 이게 레벨을 올릴 이유가 된다.

| 구간 | 플레이어 / 무기 | 상대 | 때릴 횟수 |
|---|---|---|---|
| 초반 | Lv1 / L1 | 슬라임 L1 (hp 28) | 4대 |
| 깊은 숲 중반 | Lv13 / L11 | 늑대 L12 (hp 106) | 3대 |
| 동굴 끝 | Lv28 / L22 | 버섯 L23 (hp 439) | 5대 |

### 드랍 규칙
- **떨굴 확률**: 몬스터 종류·레벨과 무관하게 **모두 10%로 동일** (`CONFIG.equipment.dropChance`)
- **레벨**: 잡은 **몬스터의 레벨과 같다** — L23 무기를 원하면 L23 몬스터를 잡아야 한다
- **종류**: 몬스터마다 정해져 있다

| 몬스터 | 떨구는 무기 |
|---|---|
| 슬라임 | **DAGGER** 단검 |
| 늑대 | **SWORD** 검 |
| 버섯 | **AXE** 도끼 |

> 세 무기의 성능은 같고 무기 레벨의 영향도 작으므로, 이 표는 "무엇이 더 센가"가 아니라
> **원하는 손맛의 무기를 얻으려면 누구를 노릴지**를 정해줄 뿐이다.
> 도끼를 쓰고 싶으면 버섯을, 단검을 쓰고 싶으면 슬라임을 사냥하면 된다.

## 파일 구조
```
index.html        진입점
css/style.css     화면 레이아웃 (픽셀 확대 렌더링)
js/config.js      모든 밸런스 수치 (여기만 고치면 게임 난이도 조정됨)
js/util.js        수학/랜덤 유틸
js/sprites.js     도트 스프라이트 정의 + 절차적 생성 (나무, 풀, 이펙트, 무기 3종)
js/world.js       지형 생성(연못·흙길·공터·꽃밭), 충돌, 지형 렌더링
js/ambient.js     분위기 연출 (꽃가루, 낙엽, 수면 반짝임)
js/minimap.js     구석 미니맵 / 전체 지도
js/save.js        localStorage 저장·불러오기, 자동 저장
js/player.js      플레이어 이동 / 공격 / 레벨업 / 포션 사용 / 무기 장착
js/enemy.js       몬스터 공통 뼈대 (체력·피격·넉백·사망·레벨표시·끼임탈출)
js/slime.js       슬라임 — 폴짝 다가와 몸통 박치기
js/mushroom.js    버섯 — 제자리에서 포자를 쏘는 포탑
js/wolf.js        늑대 — 웅크렸다 직선으로 돌진
js/projectile.js  날아다니는 탄 (포자 등)
js/items.js       포션·무기 드랍 / 자석 끌림 / 자동 줍기·교체 / 수명
js/fx.js          파티클, 데미지 숫자, 화면 흔들림
js/ui.js          HUD, 인벤토리 패널, 픽셀 폰트
js/game.js        게임 루프, 카메라, 전체 조립
```

## 지형
맵(160x120타일 = 2560x1920px)은 노이즈 두 장으로 지형을 나눈다.

| 지형 | 생성 조건 | 특징 |
|---|---|---|
| 연못 | 물기 노이즈 > `waterLevel` | **통행 불가**. 수면이 반짝인다 |
| 모래사장 | 물기 노이즈 > `shoreLevel` | 연못 둘레. 부들이 자란다 |
| 흙바닥 공터 | 개방도 노이즈 < `clearingLevel` | 나무가 없는 열린 땅 |
| 꽃밭 | 개화 노이즈 > `meadowLevel` | 꽃이 빽빽하다 |
| 숲 | 개방도 노이즈 > `treeLevel` | 높을수록 빽빽. 침엽수가 섞인다 |

여기에 가로·세로로 **흙길**을 내서 길잡이로 삼는다(맵이 크면 줄 수가 늘어난다). 타일 경계는 서로의 색을 흩뿌려(디더링) 직선이 보이지 않게 한다.

같은 "풀" 타일이라도 **어느 지역이냐에 따라 다른 바닥**으로 그려진다 (밝은 잔디 / 그늘진 잔디 / 돌바닥).
지역 경계도 타일 경계와 같은 방식으로 흐려지므로 자연스럽게 넘어간다.

## 저장 (4주차)
진행 상황은 **5초마다 이 브라우저에 자동 저장**되고, 탭을 닫기 직전에 한 번 더 저장한다.
다시 열면 저장된 지점에서 이어서 시작한다. `N` 키로 새 게임을 시작할 수 있다(확인을 한 번 묻는다).

맵 전체를 저장하지 않고 **맵을 만든 시드(seed)만** 저장한다. 같은 시드로 다시 생성하면 지형이
그대로 재현되므로 저장 용량이 아주 작다 (실측 약 350바이트).

| 저장하는 것 | 저장하지 않는 것 |
|---|---|
| 맵 시드, 플레이어 위치·체력·레벨·경험치 | 지형 (시드로 재생성) |
| 처치 수, 사망 수, 포션 수 | 몬스터 (어차피 계속 재등장) |
| 장착 무기 종류·레벨, 바닥에 떨어진 아이템 | 파티클·이펙트 |

저장 형식이 바뀌면 `Save.VERSION` 을 올린다 — 옛 저장은 조용히 무시되고 새 게임이 시작된다.
저장된 자리가 막혀 있으면(설정을 바꿔 지형이 달라진 경우) 시작 지점으로 되돌린다.

## 미니맵 (4주차)
지형을 **1타일 = 1픽셀**로 미리 그려두고 필요한 부분만 잘라 쓴다. 지형은 변하지 않으므로
맵을 만들 때 한 번만 그리면 되고, 움직이는 것만 매 프레임 점으로 찍는다.

- **구석 미니맵**: 플레이어 주변 50x38타일을 항상 표시
- **전체 지도(`M`)**: 맵 전체를 화면 가운데에 표시, 여는 동안 시간 정지.
  배율은 맵 크기에 맞춰 자동으로 정해진다(도트가 뭉개지지 않게 정수 배율만 쓴다)
- 점 색: 흰 십자=플레이어, 몬스터=레벨 색, 노랑=포션, 흰색=무기. 나무는 짙은 초록으로 찍어 숲 밀도가 보인다

## 밸런스 수정하는 곳
`js/config.js` 하나만 열면 플레이어 속도, 공격력, 슬라임 레벨별 능력치, 스폰 수를 전부 바꿀 수 있음.
2주차 수치(포션 드랍 확률/회복량/최대 소지/자석 범위/지속시간)는 `CONFIG.items`에 모여 있음.
무기 수치(종류별 배수/쿨다운/사거리/판정, 무기 레벨 배수와 색, 드랍 확률)는 `CONFIG.weapons`·`CONFIG.equipment`에 모여 있음.

> 무기 종류를 새로 넣을 때는 `damageMult / cooldown` 이 다른 무기와 같은 값(2.5)이 되도록 잡아야 성능이 균형을 유지한다.
